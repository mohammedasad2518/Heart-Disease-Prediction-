> Heart Disease Prediction is a Machine Learning project that predicts whether a patient is at risk of heart disease using healthcare data and predictive analytics.  
> Built using Python, Scikit-learn, Pandas, NumPy, and Jupyter Notebook.

---

## 📌 Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Visualization of health parameters
- Machine Learning model training
- Heart disease prediction
- Model accuracy evaluation

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📂 Dataset
The dataset contains medical attributes such as:
- Age
- Sex
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Blood Sugar
- ECG Results
- Exercise-induced Angina
- And more...

---

## 🚀 Project Workflow
1. Import dataset
2. Data preprocessing
3. Exploratory Data Analysis
4. Feature selection
5. Model training
6. Model evaluation
7. Prediction generation

---

## 📊 Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (if used)

---

## 🎯 Objective
The goal of this project is to predict the likelihood of heart disease using Machine Learning techniques and healthcare data analysis.

---

## 📈 Results
The model achieves high prediction accuracy and helps identify important health factors affecting heart disease.
